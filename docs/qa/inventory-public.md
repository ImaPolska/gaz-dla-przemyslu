# Publikacja Playground · zakres kontroli

- Cztery dokładne URL: pełny prototyp C oraz historyczne A/B/C, każdy w świeżym kontekście przeglądarki.
- Automatyczny start bez klikania Run, importowania pliku, logowania lub poprawiania instancji.
- Wyrenderowana strona główna z nagłówkiem projektu; poprawne pobranie publicznego blueprintu i zasobów.
- Odczyt wersji PHP/WordPress, aktywnego motywu, listy wtyczek i debug.log.
- Pełny C: wszystkie adresy z mapy, prawdziwe 404, `[[X]]` niezmienione; zrzut desktop i mobile.
- A/B/C: widok główny oraz `/oferta/cena-stala/`; stare tagi bez zmian.
- Niepowodzenia: brak zasobu lub CORS traktowany jako niezaliczony start; brak cache między kontekstami.
- Test publicznego linku nie zastępuje odbioru treści i edycji przez zleceniodawcę.
